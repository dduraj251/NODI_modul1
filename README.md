# Nauka o danych – Moduł 1

Repozytorium zawiera zadania wykonane w ramach zajęć z przedmiotu Nauka o danych.

Do wykonania zadań wykorzystano zbiór danych Students Performance in Exams, zawierający informacje o wynikach uczniów z matematyki, czytania i pisania.

## Pliki

- `modul1.py` – rozwiązania zadań 1–49.
- `StudentsPerformance.csv` – oryginalny zbiór danych.
- `StudentsPerformance_zapis.csv` – zapisany zbiór danych.

## Uruchomienie

Do uruchomienia programu potrzebne są biblioteki:

- pandas
- numpy
- matplotlib

Program można uruchomić poleceniem:

    python modul1.py
